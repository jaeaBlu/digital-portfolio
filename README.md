## 🚀 How to Deploy Online (Get a Public Link for Your Instructor)

You can publish this portfolio online for **100% free** using any of the three popular hosting platforms below:

### 🌟 Option 1: Netlify Drop (Easiest — Instant Link in 30 Seconds, No Code or Setup)
1. Open your web browser and go to [https://app.netlify.com/drop](https://app.netlify.com/drop) (log in with GitHub or your email).
2. Drag and drop the entire `britney-lumod-portfolio` folder (or the `britney-lumod-portfolio.zip` file) into the upload box on the screen.
3. Netlify will instantly deploy your website and give you a public URL (e.g. `https://britney-lumod.netlify.app`).
4. **Copy and send that public URL to your instructor!**

---

### 🐙 Option 2: GitHub Pages (Standard for IT Students & Developers)
1. Log in to [GitHub](https://github.com) and create a **New Repository** (e.g., named `portfolio` or `britney-portfolio`). Set it to **Public**.
2. Click **"uploading an existing file"** and drag all files from this folder into the repository, then click **Commit changes**.
3. In your GitHub repository, click on **Settings** (top tab) → **Pages** (left sidebar).
4. Under **Branch**, select `main` (or `root`) and click **Save**.
5. Within 1 minute, GitHub will provide your live public URL:
   `https://<your-github-username>.github.io/portfolio/`
6. Share this link with your instructor!

---

### ▲ Option 3: Vercel (Fast & Production-Grade)
1. Go to [https://vercel.com](https://vercel.com) and sign in with GitHub.
2. Click **Add New...** → **Project** and select your GitHub repository.
3. Click **Deploy**. Vercel will automatically build and give you a public URL (e.g., `https://britney-lumod.vercel.app`).

## 💻 Local Testing
To preview the website locally anytime:
- Double-click `index.html` to open it directly in any browser.
- Or run a local server in PowerShell / Terminal:
  ```bash
  python -m http.server 5500
  ```
  Then visit [http://localhost:5500](http://localhost:5500) in your browser.
